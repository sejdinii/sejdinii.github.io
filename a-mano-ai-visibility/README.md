# A MANO AI Visibility Benchmark

Public, aggregate-only presentation of the completed three-round pre-change benchmark.

Published files:

- `index.html` — responsive benchmark dashboard
- `a-mano-ai-visibility-summary.pdf` — two-page executive summary
- `results.json` — machine-readable aggregate results

Privacy boundary: raw answers, screenshots, traces, credentials, local paths, internal action records and disputed owner facts are intentionally excluded. The HTML carries `noindex` directives to reduce search-index contamination of later benchmark rounds.
